# Profile Overview UI - React + Tailwind

This is a responsive Profile Overview UI built using **React**, **TailwindCSS**, and **React Router**. It includes a dashboard-style layout with mobile and desktop views, a tabbed interface, and dynamic sidebar navigation.

![Screenshot](./screenshot.png) <!-- Replace with an actual screenshot path if you have one -->

## ✨ Features

- Responsive design for mobile and desktop
- Tabbed navigation ( `Profile`, `Dashboard`)
- Sidebar for navigation
- Mobile bottom navigation
- Profile card with social links
- Clean and modern UI using TailwindCSS
- Route-based navigation using React Router

## 🛠️ Tech Stack

- [React](https://reactjs.org/)
- [TailwindCSS](https://tailwindcss.com/)
- [React Router](https://reactrouter.com/)
- [Lucide Icons](https://lucide.dev/)
